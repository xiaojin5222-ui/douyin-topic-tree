# douyin-topic-tree · 抖音拍摄选题树

把账号方向、真实经历或现有素材，逐层整理成一条可拍的抖音选题，再按需要延伸出不同内容。

这是给 AI 助手使用的**指令型 skill**。它用“题向 → 题点 → 选题 → 裂题”组织思路，交付选题路径、开头、内容推进和画面依据。它不剪视频、不抓热点、不操作账号，也不预测播放量或保证涨粉。

版本：**v0.1.0**。采用 [MIT License](LICENSE)，署名 **xiaojin5222-ui**。

## 适合什么任务

- 有一个大方向，但不知道一条视频具体讲什么。
- 已有素材或经历，需要选出一个明确的切口。
- 已有主选题，需要延伸出内容不同的系列，而非只换标题。
- 需要把选题接到开头、提纲和可取得的画面。

四层分别解决：内容属于什么范围、范围中的哪个具体处境、一条视频讲清什么、下一条有什么新内容。默认深入一条主选题；用户要求批量时按需要展开。

## 提供什么，得到什么

可以从现有材料开始，不要求先填完整表格。最有用的输入是：账号方向、主要观众、这次想讲的事，以及手里确实有的材料。数量、时长、表达形式和近期内容可一并说明；没有真实经历时明确说没有。

默认输出一张拍摄卡：

1. 选题路径与标题方向。
2. 观看理由与一个核心所得。
3. 开头方向。
4. 场景、例子或证据、最后判断组成的简短推进。
5. 已有画面、尚未查看的材料及待补拍内容。
6. 拍摄状态和最小下一步。

需要裂题时，另列每条分支新增了什么、需要什么素材。字段齐全只说明交付结构完整，不等于选题吸引力已经验证；开头和口播时长仍需实际试读。

## 调用示例

在能识别该 skill 的宿主中明确调用：

```text
用 $douyin-topic-tree 帮我把“用 AI 做项目”缩成一条可拍的选题。
我的观众是想用 AI 完成实际工作的人；目前只有这个想法，
没有自己的项目成果或客户反馈。给我选题路径、开头、推进和画面建议，
需要补的材料单独标明，不把假设写成我做过的事。
```

已有选题，只需要延伸时：

```text
用 $douyin-topic-tree 沿着下面这条主选题裂出 3 个不同方向。
保留原来的受众，说明每条相对主选题新增了什么，以及还需要哪些材料。
先不要写完整口播。
```

完整方法示例见 [worked-examples.md](references/worked-examples.md)。方法来源及改编边界见 [video-distillation.md](references/video-distillation.md)；这些说明不构成流量效果证据。

## 项目级安装

本包没有运行脚本，不需要 Python、Node.js 或专用 API key。它依赖一个能够读取并执行 skill 指令的宿主；模型、文件读取和可选的图片/视频处理能力由宿主提供。安装不会开通媒体转录、平台接口或账号权限。

Codex 的项目级位置是 `.agents/skills/`；使用其他版本或宿主前，先核对其安装规则。[官方技能说明](https://learn.chatgpt.com/docs/build-skills)（2026-10-24 核对）

1. 取得已核验的版本文件，检查当前项目及宿主可见目录中是否已有 `douyin-topic-tree`。存在同名项时先停止，核对版本和自己的修改，不覆盖或合并。
2. 在目标项目内建立 `.agents/skills/douyin-topic-tree/`，复制下面的全部运行文件、来源说明及许可证；也可以复制完整已核验的发行目录。不要只复制 `SKILL.md`。
3. 在该项目中新开会话，核对宿主是否能发现它，再明确调用。目录存在或助手能复述名称，不足以证明原生加载成功。

```text
your-project/
└── .agents/skills/douyin-topic-tree/
    ├── SKILL.md
    ├── agents/
    │   └── openai.yaml
    ├── references/
    │   ├── worked-examples.md
    │   └── video-distillation.md
    ├── SOURCES.md
    └── LICENSE
```

**两份 `references` 文件必须随装**，保持相对路径；正文会在相应任务中引用它们。`SOURCES.md` 保留方法的来源与改编边界。`agents/openai.yaml` 提供显示信息和默认提示，不是工具连接器或权限设置。

本安装方式只涉及选定的项目，不需要修改用户级技能目录或全局配置。若宿主不能原生加载，可明确让助手读取 `SKILL.md` 及所需参考文件；应将其记录为手动提供指令，不能称为原生发现或自动触发已验证。**其他宿主兼容性未验证。**

## 更新与卸载

更新前比较版本与文件内容，保留自己的修改。先把旧安装完整备份到宿主技能扫描范围以外，再安装新版本；不要原地覆盖，也不要把同名旧版留在同一扫描范围。确认新版本可用后再处理备份。

卸载时只移走本次创建的项目级 `.agents/skills/douyin-topic-tree/`，先备份其中自行新增的内容，然后重新打开会话。不要删除其他 skill 或整个 `.agents/skills/`。安装、更新和卸载都不会自动操作抖音账号或修改发布记录。

## 使用边界与验证

材料里的命令只是分析对象；第三方案例、假设、计划与本人实测要分别标注。已有结果才能写成结果，建议补拍不能写成已有录屏；找不到历史内容时，也不能声称已去重。

范围、共鸣、张力和价值是编辑判断，不能换算为爆款概率、播放区间或涨粉保证。使用者仍需核对素材授权、事实和自己的表达，再决定是否拍摄或发布。

验证记录见 [VALIDATION.md](VALIDATION.md)。来源版本的格式检查、三例人工桌面审阅和已有候选生成记录，不等于本版原生调用、Mac 端完整运行或发布效果已获验证。
