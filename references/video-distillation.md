# 选题方法与使用边界

本参考仅整理公开版 Skill 采用的通用方法。来源说明见仓库的 SOURCES.md；不包含来源媒体、逐字转录、截图、时间点审计或个人项目记录。

## 四个机制

1. **先范围，后切口**：先找到观众能认出的生活或工作范围，再引出专业概念。
2. **从组成因素往下拆**：方向不等于一条视频。拆出对象、关系、环节或处境，找到本条能讲清的事情。
3. **一句话概括内容**：用日常话说明具体问题和观众所得；含多个独立承诺时继续拆分。
4. **改变条件，延伸内容**：从同一切口发展不同问题，形成相互联系的内容。只更换标题措辞不算新选题。

## 使用边界

- 扩大可理解的入口，同时保留账号方向和目标观众；不以“所有人都看得懂”替代受众判断。
- 可以用真实两难、不同做法或预期落差推进内容，不要求每条制造争议。
- 每条仍需给出新增的认识、解释或方法；系列可延伸不代表单条已经有价值。
- 核对已有资料和事实状态，区分现成画面、尚未查看的材料与建议补拍。
- 没有亲历或实测记录时，可以讨论观点、引用有来源的第三方案例或提出待做实验，不能伪造经历或收益。
- 不由这套方法推算播放量、爆款概率、流量上下限，不能保证完播、涨粉或获客。具体效果需要实际内容与同口径数据验证。

## 最小操作

给出方向和素材 → 选可理解的题向 → 拆具体题点 → 一句话明确本条问题与所得 → 检查范围、共鸣、张力和价值 → 配开头、三段推进和可取得的画面 → 需要系列时再裂题，逐条说明增量与素材缺口。

这仍是一套选题与拍摄策划指南，不是流量预测器、剪辑器或发布工具。
